# Reference Implementation Matrix — 2026-09-09

This matrix converts inspiration into explicit production decisions. A reference may contribute an idea without contributing code.

| Surface | Primary donor/reference | Production decision |
|---|---|---|
| Overall chassis | React Bits Portfolio | Next/React/Motion/Lenis structure; custom information architecture and art direction |
| Typography | koloNatalie + Aitezaz + Aceternity | Large display serif/sans contrast, short copy, generous whitespace, restrained masks/reveals |
| Navigation | React Bits + Motion Primitives | Small floating pill navigation, minimal motion, strong keyboard/focus behavior |
| Smooth scroll | React Bits + MotionFolio | Lenis only when reduced-motion is not requested; no scroll hijacking |
| Section reveals | Motion Primitives + MotionFolio | Blur/translate/opacity reveals with short travel and one-shot viewport triggers |
| Projects | React Bits + Natalie | Image/visual-first project rows; six projects receive different proof narratives rather than identical cards |
| Project transition | Aitezaz + Motion Primitives | Later phase: shared-image/morph or mask transition where it improves continuity |
| Skills / stack | React Bits + Kintarowwwards | Tactile grouped chips; semantic grouped text remains available to crawlers and assistive tech |
| Capabilities | Aceternity minimal layouts | Large typographic rows, low chrome, outcome-oriented descriptions |
| Experience | React Bits | Compact timeline/list; public-safe enterprise information only |
| Certifications / education | Aceternity + custom | Separate visual modules rather than one CV credentials block |
| Services | Custom + Aceternity composition | Outcome-based conversion layer, not freelancer-marketplace packaging |
| Contact | React Bits + Motion Primitives | Strong final CTA, direct email/LinkedIn/GitHub, restrained hover/magnetic treatment |
| Case studies | MotionFolio + custom evidence model | Real evidence, decisions, visuals, validation and outcomes; no generic template filler |
| WebGL / physics | React Bits / Kintarowwwards | Optional and isolated; only keep if performance-safe and meaningful |
| Mobile | Custom | No desktop spectacle squeezed onto phones; preserve hierarchy and proof |
| Reduced motion | React Bits / MotionFolio | Disable Lenis/state motion where requested; content remains complete |
| SEO / AI | Existing governed architecture | SSR/static meaningful content, schema, sitemap, robots, /profile.json, /projects.json, /llms.txt |

## Current synthesis
The first production scaffold intentionally starts quieter than the final art direction. It establishes the semantic hierarchy, project-specific visual system, typography, content model and motion infrastructure. Real project imagery and deeper interactions are the next visual-production layer.
