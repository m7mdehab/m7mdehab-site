**Status:** COMPLETE

## Objective

Re-audit the existing reference pool against the radically shorter homepage architecture, expand with implementation-focused references, extract mechanisms rather than aesthetics, reject patterns that recreate the current CV-like failure, and produce three materially different prototype directions.

## Existing pool re-audit

### React Bits Portfolio
Use for hero memory point, smooth interaction, project-first presentation, animated navigation/CTA and selective shader/background ideas. Reject its default full skills/experience/education hierarchy as an IA donor.

### Motion Primitives
MIT/open-source. Use as the main micro-motion vocabulary: text/group reveals, text loops, progressive blur and morphing/transitional UI. It does not determine page architecture.

### Aceternity UI
Use selected high-level composition ideas: image-grid/parallax heroes, logo-cloud patterns, project/image layouts, CTA/footer composition. Reject SaaS hierarchy, “trusted by” semantics and decorative beams/glows unrelated to Mohammed's work. Verify licensing before code reuse.

### Kintarowwwards
MIT. Use kinetic confidence, moving-text rhythm and interaction quality. Reject its large roadmap/stack volume on Home.

### MotionFolio
MIT. Use GSAP + ScrollTrigger + Lenis architecture, reusable animation utilities, short pinned/project-transition mechanics and reduced-motion ideas. Reject terminal/AI-assistant gimmicks and long scroll hijacking.

### koloNatalie
MIT. Use its motion restraint, project entry/reveal rhythm, performance-conscious GSAP implementation, centralized data and sparing magnetic interactions. Do not copy its conventional stack/testimonial structure.

### Aitezaz
The historical source identity is ambiguous in current search results. Keep only the high-level principles already documented; do not treat any newly found Aitezaz site as a verified implementation source without exact identification.

## Expanded references

Closest open-source implementation reference for the requested credibility rail. Useful mechanics: seamless horizontal loop, reverse direction, repeated content, pause on hover, arbitrary children. ### Codrops spatial / GSAP Flip gallery patterns
Strong reference for asymmetrical project galleries, parallax depth, reveal-on-entry and morphing an item into a detail state. Reuse the item-to-detail idea; reject artificial infinite-scroll ownership / scroll hijacking.

### Aceternity image/parallax hero patterns
Useful for combining identity with multiple spatial images. Adapt with real project evidence fragments rather than generic photography.

## Extracted system principles

1. Project evidence becomes the shared graphical alphabet: probability curves, agent/provenance lines, SAR textures, segmentation masks, map contours, commerce/browser fragments and mobile product states.
2. One signature interaction per chapter; do not make every control perform a different trick.
3. Replace slide-like numbered sections with page continuity: shared visual motifs, overlapping fragments and controlled tonal transitions.
4. Typography is hierarchy, not the whole visual identity. Spectacle scale is reserved for one or two moments.
5. The logo rail is credibility compression, not decorative brand theater.

## Prototype shortlist

### 1. Cinematic Systems Portfolio
Layered project-evidence “system atlas” hero; short sticky three-project stage; integrated kinetic credibility rail; graphical problem→system transformation. Highest memorability and complexity.

### 2. Spatial Evidence Gallery
Compact editorial identity with floating/cropped evidence pieces; asymmetrical gallery where evidence dominates and selected items morph/expand; quiet monochrome rail. Strong exhibition-like personality; mobile complexity is the main risk.

### 3. Kinetic Editorial / Product
Fastest and most recruiter-friendly. Compact typographic identity paired with one sharp evidence panel; three project states with rapid hover/focus transitions rather than long pinning; shallow credibility rail; concise graphical Solve/Think chapter. Best performance/Arabic/mobile prior, but must avoid becoming too safe.
